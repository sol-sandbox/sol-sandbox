# Sol-Sandbox

**Sol-Sandbox** is an educational Solana memecoin market simulator built to help users understand volatile token market mechanics before risking real capital.

The project is currently a working prototype with a live web demo, a simulated DEX-style chart, wallet-based buy/sell actions, PnL tracking, dynamic liquidity, configurable bot-driven market behavior, market controls, and shared simulation sessions.

>
> Current public prototype version: `V13.16.1`

## Purpose

Sol-Sandbox is designed as a public educational tool. It is not meant to encourage speculation. The goal is to help new Solana users learn how volatile memecoin markets behave in a safe simulation environment.

The simulator focuses on concepts such as:

- Liquidity and sell pressure
- Bonding curve and DEX-style market behavior
- Wallet-based entries and exits
- Bot-driven buy/sell activity
- Rugs, distribution, panic, and market psychology
- PnL tracking without real financial risk
- Shared simulation sessions for learning with other users

## Current prototype features

- Live simulated market chart
- Wallet-based buy and sell actions
- PnL and position tracking
- Dynamic liquidity / pool behavior
- Configurable bot market engine
- Market controls and simulation speed controls
- Early shared simulation sessions
- Room/player separation groundwork
- Railway-based frontend/backend deployment
- FastAPI backend and React/Next.js frontend architecture

## Why this matters for Solana

Solana has a large community of new users interacting with volatile token launches, meme markets, liquidity pools, and wallet-based trading behavior. Many users learn these mechanics only after losing real funds.

Sol-Sandbox gives users a hands-on way to understand these systems without using real capital. This supports risk awareness, education, and safer onboarding into the Solana ecosystem.
