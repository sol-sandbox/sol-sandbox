# Sol-Sandbox Roadmap

## Current stage

Sol-Sandbox is a working educational prototype with a live frontend/backend deployment, simulated DEX chart, wallet actions, dynamic liquidity, bot-driven market behavior, PnL tracking, and shared simulation session groundwork.

## Short-term priorities

### 1. Stability and infrastructure

- Keep a stable public demo link available for reviewers and early users.
- Improve Railway deployment reliability for frontend and backend services.
- Improve database performance and persistence.
- Add safer backup and rollback workflows.

### 2. Cross-browser and mobile support

- Test and polish Chrome, Edge, Firefox, and mobile browsers.
- Improve responsive layout so core controls remain reachable on tablets and phones.
- Make wallet controls, chart, market controls, and transactions usable on smaller screens.

### 3. Shared simulation sessions

- Make shared rooms easier to create and join.
- Improve room status visibility.
- Keep each user's own wallets private and separated.
- Reduce stale/old room clutter.
- Add small professional player trade markers on the chart.

### 4. Educational onboarding

- Add a guided beginner mode explaining core concepts step by step.
- Explain liquidity, sell pressure, bot behavior, rugs, wallet distribution, and PnL in simple language.
- Keep experienced mode available for users who want a free sandbox.

### 5. Public release polish

- Add privacy, contact, terms, and basic legal pages.
- Improve screenshots and project documentation.
- Collect feedback from early testers.

## Longer-term direction

- Improve the professional web-app architecture around the existing prototype.
- Expand realistic market scenarios such as slow rugs, distribution, panic, reaccumulation, and bundled-wallet behavior.
- Add deeper wallet-analysis learning tools, including a future bubble-map / wallet-cluster training view.
- Continue positioning Sol-Sandbox as an educational tool for understanding market mechanics before risking real funds.
