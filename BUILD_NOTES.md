# Grant Plan

## Requested amount

`$2,500`

## Main purpose

The grant would primarily be used to turn the current working prototype into a more stable public educational tool.

## Planned use of funds

### Infrastructure and hosting

- Reliable frontend/backend hosting
- Database performance improvements
- Deployment reliability
- Backups and rollback safety
- Stable public demo availability

### Cross-browser and mobile compatibility

- Browser testing and fixes
- Mobile/tablet responsive UX improvements
- Layout fixes for wallet controls, chart, market settings, and transaction views

### Shared simulation sessions

- More reliable room creation and joining
- Clear room status indicators
- Better player/wallet separation
- Cleaner shared-session UX for early user testing

### Educational onboarding

- Beginner-friendly explanations
- Guided first-run experience
- Safer learning flow for users who do not yet understand liquidity, rugs, bots, or wallet behavior

### Public availability from Germany

- Privacy page
- Contact page
- Terms / basic legal pages
- General publication polish

## Milestone idea

### Milestone 1: Stable public demo

- Keep the current prototype running on a stable public link.
- Improve hosting reliability and deployment safety.
- Add basic public documentation and screenshots.

### Milestone 2: Public testing readiness

- Improve mobile and cross-browser compatibility.
- Improve shared simulation session reliability.
- Add beginner onboarding and basic legal/privacy pages.

### Milestone 3: Community learning release

- Run early public testing with a small group of users.
- Collect feedback.
- Improve educational explanations and market-mechanics clarity.
